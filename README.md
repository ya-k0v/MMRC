# MMRC

Платформа управления медиаконтентом и цифровыми экранами. Один сервер — и все устройства показывают именно то, что нужно, в нужном формате и без ручного вмешательства.

## Что умеет

- **Живое вещание** — HLS-стримы с автоматическим подбором качества (FFmpeg)
- **Плейлисты и расписания** — серверное управление, автолупинг, показ по времени
- **Конвертация всего подряд** — PDF/PPTX в изображения, видео в совместимый формат, умное пережатие
- **Быстрый импорт** — загрузка по ссылке (yt-dlp) или из файла
- **Ночная оптимизация** — тяжёлое перекодирование выполняется в фоне, в нерабочие часы
- **Удалённое управление экранами** — установка приложения, запуск/остановка, статус устройства
- **Доступ по ролям** — админ / спикер / герой, вход по логину или через корпоративный LDAP/AD
- **Работа в реальном времени** — обновления сразу на всех экранах (WebSocket)
- **Масштабирование** — от одной машины до связки с балансировщиком, PostgreSQL и S3 (MinIO)

## Не подведёт в самый нужный момент

- **Тяжёлая обработка не роняет систему.** При перекодировке ffmpeg забирает лишь часть процессора — лимит сервер подбирает сам по числу ядер хоста (можно задать вручную). Остальные сервисы и сам сервер остаются отзывчивыми.
- **Каждый сервис на своём «поводке»** — память и число процессов ограничены, логи не разрастаются без предела.
- **Секреты не дефолтные.** Ключ JWT и пароль Redis генерируются при установке сами. Предустановленного «admin/admin» не существует — первый администратор создаётся при первом открытии страницы.
- **Безопасность из коробки** — контейнеры работают с минимальными привилегиями, зависимости регулярно проверяются и обновляются.

## Быстрый старт

```bash
curl -fsSL https://raw.githubusercontent.com/ya-k0v/MMRC/v340/install.sh | sudo bash
```

Установщик сам поставит Docker, предложит базу (SQLite или PostgreSQL), хранилище (локальный диск или S3) и настроит SSL. Останется только открыть адрес сервера, создать администратора и добавить экраны.

## Из чего состоит

| Сервис | За что отвечает |
|--------|-----------------|
| `mmrc` | API, веб-панели, обработка медиа, nginx |
| `sqlite` / `postgres` | база данных |
| `redis` | очередь задач и уведомления |
| `streamer` | выносная перекодировка (опционально) |
| `minio` | объектное хранилище / S3 (опционально) |

## Управление

- **Панели:** админ-панель `/admin.html`, панель спикера `/speaker.html`, аналитика `/analytics.html`
- **CLI:** `mmrc status`, `mmrc logs`, `mmrc update`, `mmrc backup`, `mmrc ssl`, `mmrc stop`, `mmrc start`

## Клиенты

| Клиент | Платформа | Особенности |
|--------|-----------|-------------|
| Android TV | Android | киоск-режим, автозапуск, самовосстановление |
| MPV Player | Linux | аппаратное ускорение |
| Browser | Web | HLS / DASH / MP4, PWA |

## Для разработки

```bash
make init            # .env из .env.example
make up              # запуск (SQLite, локальное хранилище)
make up-pg           # запуск с PostgreSQL
make build           # сборка образа
npm run test:unit    # юнит-тесты
```

## Замечание по доступу

Для двух функций — обновления прямо из админки и конвертации PPTX→PDF — приложение использует docker-сокет. Это осознанный компромисс; при желании его легко отключить (инструкция в DOCKER.md). Внутри контейнеров включена защита от повышения привилегий.
